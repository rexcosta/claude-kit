# The `claude-kit` Repository

## PRs

- Do not use `git push` for the `main` branch. Make each change in a branch, and send the branch as a PR.
- Before you make a PR, use the `pr-description` agent. Tell the agent which checks you did.
- Show the title and the body from the agent to the user before you make the PR.
- Do not merge a PR. The user merges the PRs.
