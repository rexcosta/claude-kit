# STE Word List

This list gives the technical nouns (TN) and the technical verbs (TV) that all the users of the plugin can use. Rule 1.5 and rule 1.12 of ASD-STE100 let you use these words. The STE checker reads this list.

Do not add your words to this list. Add them to the word list of the user. To add a word for all the users, change this list in the `claude-kit` repository.

Instructions for a new word:

- Add a word only if it is in a category of rule 1.5 or rule 1.12.
- Do not add a word that the dictionary gives as an approved word with the same part of speech.
- Use one technical noun for one item (rule 1.11).
- In the "Forms" column, write only the forms that the checker cannot make. The checker adds "s" or "es" to a technical noun. It adds "s", "es", "d", or "ed" to a technical verb.
